# Fictional training example

Cloud Library is an invented practice setting. These bilingual examples demonstrate
Postern's chapter quizzes and final exam; they are not a real organization's material
or a workplace training course. The answer is stated in each prompt so a demo can
be completed without separate handouts.

Demo mode uses these examples only when no private training directory is present.
Production installations keep their own `quizzes.json`, `final_exam.json` and
`captions/` in the private data directory's `training/` folder.

The `sample-` question IDs deliberately differ from private course IDs. Changing
an answer or its options requires a new ID; the sample ID lock lives in
`tests/postern/quiz_ids.lock.json`.

The example includes nine chapters to exercise the current Chapter 9 prerequisite
for the 20-question final exam. It includes no video transcript; see the
[caption format notes](captions/README.md) for private tracks.
